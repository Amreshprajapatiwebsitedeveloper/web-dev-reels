# Day 8 — CSS kya hai?

**HTML** = website ki body (structure) · **CSS** = kapde + makeup (colors, fonts, spacing, design)

```css
selector { property: value; }
h1 { color: pink; }
```

| Shabd | Matlab |
|---|---|
| selector | Kisko style karna hai (`h1`, `body`, `button`) |
| property | Kya badalna hai (`color`, `background`, `padding`) |
| value | Kitna / kaunsa (`pink`, `14px`) |
| `<link>` | CSS file ko HTML se jodna |

**Pro tip:** CSS hamesha alag file (`style.css`) me likho aur `<link rel="stylesheet" href="style.css">` se jodo — ek hi CSS poori website pe kaam karti hai.

`index.html` ko browser me kholo aur khud try karo!
