# Day 3 — Links & Images (30 Days Web Dev Challenge)

| Code | Kaam |
|---|---|
| `<a href="...">` | Link (a = anchor), href = address |
| `target="_blank"` | Link new tab me khulega |
| `<img src="...">` | Photo dikhao, src = photo ka path |
| `alt="..."` | Photo ka description (photo load na ho to dikhta hai + SEO) |
| `width="300"` | Photo ka size |
| `<a><img></a>` | Clickable image |

`<img>` tag ko **close nahi karna padta**.

**Pro tip:** Har image me `alt` zaroor likho — Google isse image samajhta hai.

Kaise chalayein: `index.html` download karo → double-click.
