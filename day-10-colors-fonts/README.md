# Day 10 — Colors, Fonts & Units

## Color likhne ke 3 tarike
| Tarika | Example |
|---|---|
| Name | `color: red;` |
| Hex code | `color: #ff2e63;` |
| RGB | `color: rgb(0, 184, 245);` |

**Font badalna:** `font-family: 'Poppins', sans-serif;`

**Real example (gym website):** ek brand color (orange `#ff7a28`) buttons, headings, logo — sab pe. Heading ke liye bold font, baaki text simple. Bas 2-3 colors aur 1-2 fonts → website professional lagti hai.

**Yaad rakho:** `px` fixed hota hai, `rem` flexible. Mobile + laptop dono pe achha dikhana hai to `font-size` rem me rakho (`1rem = 16px`).
