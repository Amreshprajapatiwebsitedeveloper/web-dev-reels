# Day 4 — Lists & Navbar (30 Days Web Dev Challenge)

| Tag | Kaam |
|---|---|
| `<ul>` | Unordered list — bullet points |
| `<ol>` | Ordered list — 1, 2, 3 numbering |
| `<li>` | Har list item |
| `<li><a>` | Navbar menu ka link |

**Pro tip:** Har website ka navbar `ul` + `li` se banta hai — Google aur screen readers ise menu samajhte hain.

Bonus: `index.html` me navbar ko horizontal banane ka CSS bhi hai.
