# Day 9 — CSS Selectors

| Selector | Likhte kaise | Kis pe lagta hai |
|---|---|---|
| Element | `h1 { }` | Page ke **saare** h1 |
| Class | `.btn { }` | Jahan-jahan `class="btn"` hai |
| ID | `#logo { }` | Sirf **ek** element (`id="logo"`) |

**Real example (restaurant website):** 20 dishes pe ek hi class `.menu-item` → ek CSS se saare cards same design. Aaj ki special dish pe `#special` → sirf usko alag color.

**Yaad rakho:** class kitni bhi baar use ho sakti hai, id page pe sirf **ek** baar. Isliye zyada kaam class se hota hai.
