# Day 2 — Headings & Paragraphs (30 Days Web Dev Challenge)

| Tag | Kaam |
|---|---|
| `<h1>` – `<h6>` | Headings — h1 sabse bada, h6 sabse chhota |
| `<p>` | Paragraph (normal text) |
| `<br>` | Nayi line |
| `<hr>` | Horizontal line |
| `<strong>` | **Bold** |
| `<em>` | *Italic* |

**Pro tip:** Ek page pe sirf **one `<h1>`** rakho — Google isse samajhta hai page kis baare me hai (SEO).
