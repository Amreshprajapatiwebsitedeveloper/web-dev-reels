# Day 6 — HTML Forms (Login Form)

| Tag | Kaam |
|---|---|
| `<form>` | Poora form |
| `<input>` | User ka data |
| `type="email"` / `type="password"` | Har data ke liye alag box (password `••••` dikhta hai) |
| `<label>` | Input ka naam |
| `<button>` | Form submit |

**Pro tip:** `required` lagao to user bina bhare submit nahi kar payega. `placeholder` se box me hint dikhao.

`index.html` ko browser me kholo aur khud try karo!
