# Day 5 — Tables (30 Days Web Dev Challenge)

| Tag | Kaam |
|---|---|
| `<table>` | Poori table (`border="1"` se lines) |
| `<tr>` | Table row — ek line |
| `<th>` | Heading cell (bold) |
| `<td>` | Data cell |
| `colspan="2"` | 2 columns ko jodna |

**Pro tip:** Table sirf data ke liye (price list, timetable, report). Website layout ke liye CSS Flexbox/Grid use karo.
