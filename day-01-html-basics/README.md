# Day 1 — HTML kya hai?

**HTML = HyperText Markup Language** — website ka skeleton (dhaancha).

## Kaise chalayein
1. `index.html` download karo
2. Double-click karo — browser me khul jayega 🎉

## Is code me kya hai
| Tag | Kaam |
|---|---|
| `<!DOCTYPE html>` | Browser ko batata hai ki ye HTML5 page hai |
| `<html>` | Poora page iske andar |
| `<head>` | Page ki settings, jaise `<title>` |
| `<body>` | Jo kuch screen pe dikhta hai |
| `<h1>` | Sabse badi heading |
| `<p>` | Paragraph |
| `<button>` | Button |

**Rule:** har tag open hota hai `<h1>` aur close hota hai `</h1>` (slash ke saath).
