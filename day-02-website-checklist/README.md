# ✅ Business Website Checklist (Day 2)

Apni website ko is checklist se check karo. Jitne ✅ zyada, utne customers zyada.

## 1. Trust (Bharosa)
- [ ] Apna domain (yourbusiness.com) — free subdomain nahi
- [ ] HTTPS / SSL lock 🔒
- [ ] Asli photos, address aur Google Map
- [ ] Customer reviews / testimonials

## 2. Google pe dikhna (SEO basics)
- [ ] Har page ka clear title aur description
- [ ] Google Business Profile bana hua
- [ ] Google Search Console me website add
- [ ] Mobile pe fast (PageSpeed Insights check karo)

## 3. 24×7 Leads
- [ ] WhatsApp button har page pe
- [ ] Call button (mobile pe ek tap)
- [ ] Simple enquiry form
- [ ] Form submit hone pe email/WhatsApp alert

## 4. Apna Ghar (Ownership)
- [ ] Domain aur hosting aapke naam pe
- [ ] Instagram/Facebook se website ka link
- [ ] Email list / leads ka backup

## 5. Ads ke liye ready
- [ ] Har offer ka alag landing page
- [ ] Meta Pixel / Google Ads tag laga hua
- [ ] Thank-you page (conversion track karne ke liye)
