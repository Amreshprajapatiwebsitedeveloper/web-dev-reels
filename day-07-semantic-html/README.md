# Day 7 — Semantic HTML + SEO

`<div>` ki jagah aise tags use karo jinka naam hi bata de ki andar kya hai:

| Tag | Kaam |
|---|---|
| `<header>` | Page ka upar ka hissa |
| `<nav>` | Menu |
| `<main>` | Asli content |
| `<section>` | Alag-alag bhaag |
| `<footer>` | Sabse neeche |

**Pro tip (SEO):** Google ka bot aapke tags padhta hai. Semantic tags se use page samajh aata hai, aur website rank karti hai. `<meta name="description">` zaroor likho.

`index.html` ko browser me kholo aur khud try karo!
